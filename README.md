Portafolio de Python: Automatización y Análisis de Datos

Repositorio enfocado en soluciones prácticas de automatización de tareas repetitivas y análisis de costos operativos con Python.

Proyectos Incluidos

1. procesar_reportes.py
   - Automatización de limpieza de registros y cálculo de métricas financieras/operativas.
   - Generación de reportes limpios y ordenados en consola.

2. calcular_costos.py
   - Herramienta analítica para calcular distancias, consumo de combustible, gastos operativos y costos totales de operación.

🛠️ Tecnologías
- Python 3.14
- Automatización de Procesos
- Análisis de Datos
